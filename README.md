# ALUCI — Gardien des coutumes et traditions

React + Vite + Tailwind. Flow: **langue → mini-film (3 actes) → hero_select → monde ouvert**.

## Démarrer

```bash
npm install
npm run dev
```

## 10 Gardiens

Portraits cinématiques dans `public/heroes/*.png` (branchés dans `src/data/heroes.ts`). Remplace un fichier pour changer un héros.

## Hero select

Écran cinématique : carte portrait, vignettes scrollables, nom de gardien, bouton CONTINUER — aligné sur les maquettes WhatsApp.
